# Login System

Este proyecto es una aplicación de consola en Java que simula un sistema de login y registro de usuarios. Es una de mis primeras aplicaciones en este lenguaje y me permitió comenzar a aplicar mis conocimientos de Java. La aplicación sigue el patrón MVC (Modelo-Vista-Controlador) y los principios de la programación orientada a objetos.

## Funcionalidades

- Registro de nuevos usuarios
- Inicio de sesión para usuarios registrados
- Validación de credenciales

## Requisitos

- Java Development Kit (JDK) 8 o superior

## Ejecución

Para correr la aplicación, utiliza el siguiente comando:

```sh
java -cp ./bin App
```

## Estructura del Proyecto

- `src/`: Contiene el código fuente de la aplicación
- `bin/`: Contiene los archivos compilados
